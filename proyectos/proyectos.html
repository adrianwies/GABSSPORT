Cancha Sintética

Proyecto desarrollado en Lima, Perú, enfocado en la construcción de una cancha sintética de alto rendimiento. Se trabajó con materiales resistentes, una base nivelada y acabados pensados para brindar seguridad, durabilidad y una mejor experiencia de juego.

Superficie sintética premium

Instalación de césped sintético resistente para uso deportivo continuo.

Base nivelada

Preparación del terreno para asegurar estabilidad y buen desempeño.

Alta durabilidad

Materiales diseñados para soportar uso frecuente y condiciones exigentes.

Proyecto listo para el alto rendimiento

Un espacio deportivo seguro, moderno y funcional.
